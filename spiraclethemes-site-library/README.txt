One-click demo import, theme customization, starter templates, and page builder support for Spiracle Themes.

== Description ==

Looking for a beautiful website without the hassle? Install the Spiraclethemes Site Library, pick one of our 25+ free themes on the Get Started page, and import a complete demo — pages, widgets, and settings — in a single click. No coding required.

== Get Started ==

Follow these steps to get your website up and running with the Spiraclethemes Site Library:

1. **Install & activate the plugin.** While installing a free theme by Spiraclethemes, install and activate our "Spiraclethemes Site Library" plugin, or do so manually from your Plugins page.

2. **Open the Get Started page.** After activation, click **Spiraclethemes Site Library > Get Started** in the WordPress admin menu.

3. **Pick your theme.** The Get Started page lists every theme supported by the plugin — ecommerce, blog, magazine, lawyer, and multipurpose website themes. If the theme is already installed, click **Activate**. If it is missing, click **Install** to install and activate it in one step.

4. **Import demo content.** With a supported theme active, go to **Appearance > Demo Import**. Preview and select your desired demo, then click the import button. The plugin handles content, widgets, customizer settings, and recommended plugins for you.

Need help? Contact Spiraclethemes support at http://support.spiraclethemes.com/.

== Installation ==

*** From your WordPress dashboard ***

1. Visit 'Plugins > Add New',
2. Search for 'Spiraclethemes Site Library' and install the plugin.
3. Activate 'Spiraclethemes Site Library' from your Plugins page.

== Frequently Asked Questions ==

= Does this plugin work with any WordPress theme? =

No, this plugin works only with themes developed by [Spiraclethemes](https://spiraclethemes.com/).

= What happens when I import a demo? =

The import copies the demo's pages, posts, widgets, customizer settings, and menus, and installs any recommended plugins (for example WooCommerce for shop demos) so your site looks exactly like the preview.

= Can I undo a demo import? =

Demo imports are designed to bring your site to a known starting point, so importing a new demo will overwrite existing content. We recommend importing into a fresh WordPress installation.

= How can I report security bugs? =

You can report security bugs through the Patchstack Vulnerability Disclosure Program. The Patchstack team helps validate, triage and handle any security vulnerabilities. [Report a security vulnerability.]( https://patchstack.com/database/vdp/e9d5f70c-d204-4e76-8ca5-acb82a5d04dc )
